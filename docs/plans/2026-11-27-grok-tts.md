# grok-tts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `grok-tts` skill that turns text into Grok (xAI) voice files plus word timings that HyperFrames `media-use` takes as recording lines.

**Architecture:** One stdlib-only script, `skills/grok-tts/grok_tts.py` (the same shape as `grok-image` and `grok-video`), built bottom-up in this order:

1. word timings
2. audio integrity
3. key lookup
4. API client
5. single-file CLI with cache
6. batch mode

`SKILL.md` teaches agents the HyperFrames handoff. An offline unittest suite in `tests/grok-tts/` replays the measured API responses through a stub HTTP server on 127.0.0.1.

**Tech Stack:** Python 3 standard library only (`argparse`, `urllib`, `json`, `wave`, `struct`, `hashlib`, `http.server`, `unittest`); GitHub Actions; SkillSpector.

**Spec:** `docs/specs/2026-11-27-grok-tts-design.md`

## Global Constraints

- Standard library only; must run on Python 3.12 (CI) and 3.14 (owner). No ffmpeg call except the optional `ffprobe` MP3 check.
- API base `https://api.x.ai`; endpoints `POST /v1/tts`, `GET /v1/tts/voices`; header `Authorization: Bearer <key>`.
- Text ≤ 60,000 characters per request; speed 0.7–1.5; every TTS request sends `"with_timestamps": true`.
- `output_format`: WAV `{"codec": "wav", "sample_rate": 44100}`; MP3 `{"codec": "mp3", "sample_rate": 44100, "bit_rate": 192000}`.
- Defaults: voice `eve`, language `en`, batch folder `voiceover`, timeout 300 s.
- Exit codes: 0 success; 2 bad input, detected before any API call; 1 API, network, key or file failure.
- The key is never accepted on argv, printed, logged or written; error text comes from the API's JSON `error` field and the key's source label only.
- Never read a project `.env`. Never fall through to another key source after a key is rejected. Never switch voice provider.
- Tests live in `tests/grok-tts/` (not under `skills/`). Run them with `python3 -m unittest discover -s tests/grok-tts -t tests/grok-tts -v`.
- Word shape everywhere: `{"id": "w0", "text": str, "start": float, "end": float}`.

## Review Focus

1. **A script file saved with a UTF-8 BOM** (common from Windows editors): the API receives the text without `\ufeff`. Test: Task 5 `test_text_file_bom_stripped`.
2. **Ctrl-C while files are being written:** no `.part` file is left and the previous output is intact. Test: Task 2 `test_atomic_write_interrupt_keeps_old_file`.
3. **No network** (refused connection, DNS failure): retried, then exit 1 with "could not reach". Test: Task 4 `test_unreachable_host_retries_then_fails`.
4. **The same text with a different voice or speed:** that is a new cache entry, never the old audio. Test: Task 5 `test_cache_key_changes_with_voice_speed_format`.
5. **A batch line that is empty or only speech tags:** exit 2 before any request, naming the line id. Test: Task 6 `test_batch_tag_only_line_rejected`.

import io, os, stat, struct, tempfile, unittest, wave
from pathlib import Path
from unittest import mock
from helpers import grok_tts, streaming_wav

class RepairWavTest(unittest.TestCase):
    def test_sets_real_sizes(self):
        out = grok_tts.repair_wav(streaming_wav(0.5), 0.5)
        self.assertEqual(struct.unpack_from("<I", out, 4)[0], len(out) - 8)
        self.assertEqual(struct.unpack_from("<I", out, 40)[0], 44100)

import json, os, tempfile, unittest
from datetime import datetime, timezone
from pathlib import Path
from helpers import grok_tts

NOW = datetime(2026, 11, 27, tzinfo=timezone.utc)

class KeysTest(unittest.TestCase):
